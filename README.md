# ResumeCraft – AI Resume Builder SaaS 🚀

ResumeCraft is a modern, fast, and user-friendly **Resume Builder SaaS** built with **Next.js** and **Tailwind CSS**. It helps users create professional, ATS-friendly resumes in minutes using clean templates and smart customization options.

Whether you're a student, fresher, or experienced professional, ResumeCraft makes resume creation simple, beautiful, and effective.

---

## ✨ Key Features

* 📄 Easy-to-use Resume Builder
* 🎨 Modern & Professional Resume Templates
* ⚡ Built with Next.js & Tailwind CSS
* 🌗 Dark & Light Mode
* 🧠 ATS-Friendly Resume Layouts
* ✏️ Live Resume Preview
* 📱 Fully Responsive Design
* 🔒 Secure & Scalable SaaS Architecture
* 🧾 Export Resume as PDF
* 🧑‍💼 Designed for Job Seekers & Professionals

and much more...
